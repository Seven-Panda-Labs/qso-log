# Self-hosting

> **Draft.** Written once there is something to deploy.

QSO Log is AGPL-3.0: you may run your own instance, and if you modify it and offer it over a network, you must offer the modified source to its users.

## Planned steps

1. Create a Firebase project
2. Enable Authentication, Firestore, and Hosting
3. Configure environment variables, see [configuration.md](configuration.md)
4. Build and deploy
5. Publish a privacy notice if other people use your instance

## Your obligations as an operator of an instance

If anyone other than you logs into your instance, you are handling other people's data: callsigns, contacts, and locations. Publish what you store and how to request deletion. Under GDPR, running a public instance for others makes you the controller of that data.
